# SchoolGrade 1.0

Учёт результатов учебной деятельности учащихся учреждений общего среднего образования Республики Беларусь: электронный журнал, отметки за четверти и год, поведение, аналитика (средний балл, качество знаний, СОУ, уровни), отчёты, передача данных в отдел образования.

**Общественная организация «Союз юных педагогов»**
Разработчик: Костянко Денис Александрович
Витебск, 2026

## 1. Что умеет программа

| Раздел | Возможности |
|---|---|
| Электронный журнал | Уроки по датам (тема, д/з, вид работы), текущие отметки 1–10, «н», зач., незач., осв.; цветовая подсветка уровней; ввод с клавиатуры (стрелки, Enter); подсчёт количества и среднего, расчётная отметка за период |
| Ведомость класса | Ввод отметок за четверть, год, экзамен и итоговых в одной таблице «учащиеся × предметы» (как бумажная сводная ведомость) с поведением; средний балл, КЗ, СОУ и уровень считаются сразу. Учитель заполняет столбцы своих предметов, классный руководитель — весь свой класс |
| Итоговые отметки | Четверти (или полугодия), годовая, экзаменационная, итоговая; расчётные значения по правилам аттестации; «Заполнить расчётными»; н/а с отметкой «по уважительной причине» |
| Поведение и итоги года | прим. / уд. / неуд. за четверти и год; решение педсовета (переведён, условно, оставлен, свидетельство, аттестат, медаль…) |
| Отчёты (печать и Excel) | сводная ведомость класса; анализ класса по предметам; рейтинг учащихся; пропуски; список учащихся; табель для законных представителей; успеваемость по классам и параллелям; аналитика по предметам в параллели; списки «на 9–10», «7–10», «резерв», низкий уровень, н/а; отчёт учителя |
| Отдел образования | Файл для отдела (Excel) без персональных данных учащихся; пакет `.sgdep.json`; **свод по нескольким учреждениям** для специалистов отдела |
| Данные | Классы (без ограничения количества), нагрузка (предмет, учитель, часы, подгруппы, система оценивания), личные карточки учащихся, движение (зачисление, выбытие, перевод), импорт списков из Excel/CSV и вставка списка «Фамилия Имя Отчество» из буфера обмена, сотрудники, предметы, паспорт учреждения |
| Учебный год | Сроки четвертей, закрытие периода от изменений, перевод учащихся в новый учебный год |
| Администрирование | Режим «только ведомости» (электронный журнал отключается одной кнопкой), пользователи и роли, обязательная смена пароля, правила аттестации, резервные копии (авто раз в сутки) и восстановление, журнал действий |
| Сеть | Один компьютер — сервер, остальные работают в браузере по локальной сети |

### Отметки

* **1–10 баллов**, пять уровней: низкий (1–2), удовлетворительный (3–4), средний (5–6), достаточный (7–8), высокий (9–10);
* **зач.** / **незач.** — для предметов с зачётной системой;
* **осв.** — освобождён (медицинское освобождение);
* **н/а** — не аттестован (флажок «по уважительной причине» влияет на годовую);
* **н/и** — не изучал (прибыл из другого УО / из-за рубежа);
* **н** — отсутствие на уроке (только в текущем журнале);
* поведение — **прим.**, **уд.**, **неуд.**

### Правила расчёта (настраиваются: «Администрирование → Правила аттестации»)

* отметка за четверть — среднее арифметическое текущих отметок, **математическое округление** (6,5 → 7);
* минимум отметок для четвертной — 3 (при 1 часе в неделю — 1), иначе предлагается н/а;
* годовая — среднее арифметическое отметок за четверти; н/а по уважительной причине не учитывается, без уважительной — приравнивается к 0;
* **КЗ** (качество знаний) — доля отметок не ниже 6 баллов (как в «Старт ШКОЛА»; порог меняется);
* **СОУ** — веса 10→100 %, 9→96, 8→90, 7→74, 6→55, 5→45, 4→40, 3→32, 2→20, 1→12 %;
* уровень учащегося — по самой низкой отметке.

Программа предлагает отметки, но решение всегда за учителем: любую отметку можно исправить вручную.

## 2. Установка и работа в школе

1. Скопируйте `SchoolGrade.exe` в отдельную папку на компьютере, который будет **сервером** (обычно ПК заместителя директора или кабинета информатики; он должен быть включён, пока учителя работают).
2. Запустите `SchoolGrade.exe`. Откроется окно сервера и браузер.
3. Вход: **admin / admin** — программа сразу потребует сменить пароль.
4. Заполните: «Паспорт учреждения» → «Учебный год» (проверьте сроки четвертей) → «Сотрудники» → «Предметы» → «Классы и нагрузка» → учащиеся (вручную или импорт из Excel) → «Администрирование → Пользователи» (кнопка «Создать учётные записи для всех сотрудников»).
5. Чтобы посмотреть программу на примере — «Администрирование → Резервные копии → Загрузить демо-данные» (только в пустую базу).

### Работа по локальной сети

* В окне сервера показаны адреса вида `http://192.168.1.10:8080`. Учителя открывают этот адрес в браузере на своих компьютерах — устанавливать ничего не нужно.
* Если с других компьютеров не открывается — один раз запустите на сервере `firewall_open_port.bat` **от имени администратора**.
* Поддерживаемые браузеры: Chrome / Edge / Яндекс.Браузер / Firefox (на Windows 7 — Chrome 109, Firefox ESR 115). Internet Explorer не поддерживается.
* Другой порт: `SchoolGrade.exe --port 8090`. Только локально (без сети): `--local`. Своя папка данных: `--data D:\SchoolGrade`.

### Где хранятся данные

Рядом с exe создаётся папка `SchoolGrade_data`:

* `schoolgrade.db` — вся база (SQLite);
* `backup\` — резервные копии (автоматически раз в сутки, хранятся 30 последних);
* `config.json` — порт и настройки запуска.

Если папка с exe недоступна для записи (например, `Program Files`), данные сохраняются в `%APPDATA%\SchoolGrade`. **Регулярно копируйте папку `backup` на внешний носитель.**

## 3. Соответствие законодательству Республики Беларусь

* **Аттестация.** Отметки и правила их выставления соответствуют Правилам проведения аттестации учащихся при освоении содержания образовательных программ общего среднего образования (постановление Министерства образования от 11.07.2022 № 184, с изменениями). Параметры вынесены в настройки, чтобы при изменении редакции не менять программу. *Перед вводом в эксплуатацию сверьте параметры с действующей редакцией на pravo.by.*
* **Персональные данные** (Закон от 07.05.2021 № 99-З «О защите персональных данных»):
  * разграничение доступа по ролям (учитель видит только свои журналы, классный руководитель — карточки своего класса);
  * пароли хранятся только в виде хэша PBKDF2-SHA256, обязательная смена начального пароля;
  * журнал действий фиксирует вход, изменения отметок, просмотр карточек учащихся, выгрузку списков;
  * данные хранятся только на компьютере учреждения, в интернет ничего не передаётся;
  * файл для отдела образования не содержит персональных данных учащихся.
  * Учреждению следует утвердить локальный акт (политику) обработки персональных данных и назначить ответственного.
* **Закрытие периодов**: после окончания четверти директор/заместитель закрывает период, после чего изменить отметки может только администратор (каждое изменение — в журнале действий).

> Программа является вспомогательным средством учёта. Если в учреждении ведётся официальный электронный журнал/дневник в иной системе, используйте SchoolGrade для аналитики и подготовки отчётов в соответствии с порядком, установленным в учреждении.

## 4. Разработка в VS Code и сборка exe

### Требования

* **Python 3.8.10** — последняя версия Python, поддерживающая Windows 7. Рекомендуется **32-битный** установщик (`python-3.8.10.exe`): собранный exe работает на 32- и 64-битных Windows 7, 8.1, 10, 11. На Windows 7 SP1 должно быть установлено обновление KB2533623 (обычно уже есть).
* VS Code с расширением Python (для Windows 7 — VS Code 1.70.x).
* Сторонние библиотеки для работы программы **не нужны** — только стандартная библиотека Python. PyInstaller нужен лишь для сборки.

### Запуск из исходников

```
python run_server.py --data dev_data
```

В VS Code: `F5` → «SchoolGrade (окно сервера)». Тесты: `python -m unittest discover tests -v`.

### Сборка одного exe

```
build.bat
```

Скрипт создаст `.venv`, установит PyInstaller 5.13.2, прогонит тесты и соберёт `dist\SchoolGrade.exe` с иконкой и свойствами файла (организация, разработчик). В VS Code: `Ctrl+Shift+B`.

> Собирайте именно на Python 3.8: exe, собранный на Python 3.9+, не запустится на Windows 7.

**Если pip падает с ошибкой `check_hostname requires server_hostname`.** Это ошибка старого pip из Python 3.8 при системном прокси/VPN. `build.bat` сам переписывает адрес прокси на `http://` и обновляет pip. Если не помогло:

* отключите VPN/прокси (Параметры → Сеть и Интернет → Прокси) и запустите `build.bat` снова; или
* выполните в той же консоли `set SG_NO_PROXY=1`, затем `build.bat`; или
* без интернета: на любом компьютере с доступом выполните `py -3.8 -m pip download pyinstaller==5.13.2 -d wheels` и скопируйте папку `wheels` в проект — `build.bat` установит PyInstaller из неё.

### Структура проекта

```
SchoolGrade/
├── run_server.py            точка входа (и для PyInstaller)
├── schoolgrade/
│   ├── main.py              запуск, окно сервера (tkinter), автокопии
│   ├── server.py            HTTP-сервер на стандартной библиотеке, маршрутизация
│   ├── api.py               REST API: справочники, журнал, отметки, отчёты, администрирование
│   ├── grading.py           правила оценивания: нормализация, округление, расчёт отметок, КЗ, СОУ
│   ├── reports.py           отчёты (единый формат для экрана, печати и Excel)
│   ├── xlsx.py              генерация и чтение .xlsx без сторонних библиотек
│   ├── db.py                схема SQLite, резервное копирование
│   ├── auth.py              пользователи, роли, сессии, права
│   ├── demo.py              вымышленные демонстрационные данные
│   └── static/              интерфейс: index.html, app.js, app.css, иконки
├── tests/test_grading.py    тесты правил и прав доступа
├── SchoolGrade.spec         конфигурация PyInstaller
├── version_info.txt         свойства exe-файла
├── build.bat                сборка
└── firewall_open_port.bat   открыть порт в брандмауэре
```

### Архитектура

Один процесс `SchoolGrade.exe` — веб-сервер + база SQLite. Учителя работают через браузер, поэтому нет проблем с одновременным доступом к файлу по сети (как у Excel-книг) и не нужно ставить программу на каждый компьютер. Изменяющие запросы защищены от CSRF, сессии — HttpOnly-cookie, сессия истекает через 12 часов бездействия.

## 5. Отличия от «Старт ШКОЛА»

| «Старт ШКОЛА» (Excel, 2006) | SchoolGrade |
|---|---|
| 13 книг Excel с макросами, нужен «средний» уровень безопасности макросов | Один exe, без Excel и макросов |
| До 5 классов в параллели, до 35 предметов, до 40 учащихся | Без ограничений |
| Только четвертные и итоговые отметки | Журнал по урокам + расчёт четвертных и годовых по правилам аттестации |
| Нет зач./незач./осв./н/а/н/и, поведения | Все виды отметок и поведение |
| Один пользователь (файл) | Многопользовательская работа по сети, роли, журнал действий |
| Паспорт, сотрудники, аналитика по уровням, КЗ, СОУ | Всё перенесено + рейтинги, списки, табели, пропуски, отчёт учителя |
| Файл для отдела образования | Excel для отдела + пакет для автоматического свода по району |
| Нет защиты персональных данных | Пароли, роли, аудит, закрытие периодов, резервные копии |

## 6. Идеи для следующих версий

Импорт данных из книг «Старт ШКОЛА» (после сохранения в .xlsx), календарно-тематическое планирование, расписание, личный кабинет для законных представителей, печать страниц классного журнала по установленной форме, HTTPS для сети.
